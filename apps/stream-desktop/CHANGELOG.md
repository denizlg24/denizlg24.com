# Changelog

What changed in each Stream desktop release, newest first. The GitHub release
for a version opens with its entry. Each release is a
`## <version> — <YYYY-MM-DD>` heading.

## 0.1.2 — 2026-11-09

### Changed
- Stream now looks for updates every few hours while it stays open, not only
  when it starts. Choosing "Later" waits until the next version.
- The app inside the window has been redesigned: a new home with a featured
  title and rows picked for whoever is watching, faster search that copes
  with typos, and "More like this" on every title.

## 0.1.1 — 2026-10-24

### Fixed
- Films and series play inside the app instead of opening in your browser.
- Trailers play again instead of showing a YouTube error.
- Pop-ups and ad pages from the player are blocked instead of opening
  elsewhere, and known ad and tracking requests are blocked before they load.

## 0.1.0 — 2026-10-23

### Added
- First release: Stream's web app in a native window for macOS and Windows,
  with sign-in, fullscreen playback, an offline screen and automatic updates.
