# Stream changelog

## 0.4.0 — 2026-11-22

- Fixed TV remote navigation past Continue Watching and restored the last focused column when returning to a row.
- Kept the TV keyboard responsive while search runs and reduced the number of off-screen cards rendered during browsing.
- Made My List changes appear immediately on the TV title page and in cached browse views.
- Added Screen Share to the TV menu. Enter the TV code on the Stream website, then choose a screen, window, or tab to share.
