# App Review notes for the 0.1.3 build

The October 27 review rejected build 131 under Guideline 1.4.1. Upload a new
build containing these changes before replying or resubmitting. These notes
have not been sent to Apple.

Suggested review message:

We have made citations more explicit throughout the app. Health information
now includes named, tappable references beside the estimates. These links
open the original research or issuing body’s guidance directly.

You can find them in these locations:

- Onboarding: the pace, macro profile, targets and summary steps.
- Today: the energy expenditure section.
- Progress: Strategy, Check-in, Statistics and the goal editor.
- Nutrition overview and an individual food’s nutrition breakdown.
- Today → person button → Settings → Health references & sources: the complete
  reference list, with publication titles, authors or issuing bodies, visible
  URLs, and an explanation of which information each reference supports.

Each inline reference group also has an “All references & calculation details”
link. It opens the relevant topic first. Onboarding provides the same reference
screen before account setup is complete.

The references distinguish published research from app-specific calculation
rules and explain limitations of the estimates. The health information screen
also includes a notice that the app’s estimates are not medical advice.
